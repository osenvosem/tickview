# Milestone 3 — Study Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Verify all 66 existing studies against reference evidence, add the 17 missing in-scope built-in studies, introduce the study input context (HTF/session/visible-range/comparison), and flip the study manifest to fully verified.

**Architecture:** `crates/ta` stays pure (no UI/network/filesystem): a `StudyContext` struct carries capability data beyond the candle array (closed HTF bars, session anchors, visible-range bounds, optional aligned comparison series) into `compute_with`, while `compute` keeps its signature via a default context. Goldens are const arrays generated by a committed Python reference script against the shared fixture. `xtask parity` gains study validation rules and regenerates `docs/parity/STATUS.md`.

**Tech Stack:** Rust (workspace: `ta`, `tickchart`, `app`, `xtask`), serde_json, Python 3 (golden generation only), egui scenes via `TICKVIEW_SCENE`/`TICKVIEW_SNAPSHOT`.

**Spec:** `docs/superpowers/specs/2026-10-20-reference-app-full-parity-design.md` (§6.3, §7.1–7.2, §10, §11, §13–15)

## Global Constraints

- `ta` crate has no UI/network/filesystem dependencies; `compute(id, params, cd, ax)` keeps working (additive `compute_with`).
- Config stays version 2; any new persisted field is optional with backward-compatible defaults.
- Evidence precedence (spec §7.1): extracted reference bundle metadata → official docs → independent reference → empirical. Record inference gaps in the evidence note.
- Golden goldens are deterministic const arrays vs a fixed fixture; NaN warm-up prefixes must match reference length exactly.
- Verified study entries need ≥2 test ids and ≥1 existing evidence file (`xtask` rule, task 2).
- Excluded entries require `exclusion_reason`; excluded ids may never appear in the UI.
- Gates every task end: `cargo fmt --all`, touched-crate tests; workspace-wide gates in task 14.
- Never rewrite the user's real config during QA (`TICKVIEW_*` env only; copied homes if needed).

## Review Focus

- No-lookahead: HTF resampling, ZigZag pivots, and Williams Fractals must not use future bars — prefix invariance tests pin this (tasks 9, 12).
- Warm-up NaN alignment: every golden must assert the NaN prefix length equals the reference, not just tail values (tasks 4–8, 10–13).
- Degenerate inputs: zero volume, flat price, constant series, zero denominators (Choppiness, Correlation, RVI, EaseOfMovement) produce NaN/0 per reference, never panic (tasks 6, 10, 13).
- Insufficient history: `compute` with fewer bars than the longest lookback returns all-NaN plots without panic for every id (task 14 sweep).
- Pane/scale metadata drift: pane, scale, hlines and plot count/style must match the reference metaInfo evidence per id (task 2 sweep).
