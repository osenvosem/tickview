## Datafeed session protocol (live-verified)

- Connect: `wss://data.tradingview.com/socket.io/websocket?from=chart%2F&sessionid=<uuid>` → opens (no subprotocol required).
- Server-first frame (observed): `~m~292~m~{"session_id":"0.938…-tvbs-…","timestamp":…,"release":"release_210-13","studies_metadata_hash":"58fece1e…","auth_scheme_vsn":2,"protocol":"json",…}`
- Framing confirmed: `~m~<len>~m~<json>`; replies use short keys `{"m":…,"p":[…]}`; redirect handoff via `session_id` JSON `{redirect}` (max 20 redirects/reconnects, host rotation free→pro→reconnect; `/ping` keep-alive every 10 s measuring min/max/avg — from `WSBackendConnection` source dump).
- Command surface (from shipped `TVChartApi` prototype + session client chunk `66286…`):
  `set_auth_token, chart_create_session, chart_delete_session, switch_timezone, switch_locale,
  resolve_symbol, create_series, modify_series, remove_series, request_more_data,
  request_first_bar_time, request_more_tickmarks, set_future_tickmarks_mode, request_metadata,
  all_studies_metadata, create_study, modify_study, remove_study, create_pointset, get_marks,
  get_timescale_marks, quote_create_session/add_symbols/remove_symbols/fast_symbols/set_fields/hibernate_all,
  depth_create_session/depth_set_symbol/depth_clear_symbol/depth_scale, set_data_quality(low),
  replay_create_session/delete/reset/start/stop/set_symbol/set_resolution/set_index/get_depth,
  set_broker`.
- Post-handshake commands gated by `auth_scheme_vsn: 2`; `unauthorized_user_token` path rejected
  (protocol_error) — full command cycle not replayable anonymously on release_210-13.
  Reference-grade documentation only; production feeds must use exchange APIs (ToS + fragility).
- Quote session snapshot per symbol carries ~1190 fields incl. `session-id`
  (`us_stocks_overnight`), `subsession-id`, `is-tickbars-available`, `has-no-realtime`,
  `provider-id` (`ice`), fundamentals/estimates arrays — superset of `scanner.tradingview.com/symbol?fields=…`.

## Candidate features for TickView (ranked)

1. **Exchange websocket streaming** (Binance `<sym>@kline_1m`/`@trade`/`@depth`): replaces 1-s poller; live candle updates, spread/volume. No TV dependency; protocol reference above.
2. **Bar replay**: local on cached candles (step/autoplay/speeds/jump — `_replayApi` semantics as UX spec). Zero new data sources.
3. **Study templates**: named indicator-set save/load/apply (mirror `api/v1/study-templates` shape) — persisted in config v2.
4. **Earnings/event markers**: `news-mediator/public/doc-screener/v1/events` + economic calendar → flags on time axis + legend; free public JSON.
5. **News panel**: news-mediator per-symbol feed in sidebar (headline + provider + urgency; respect paywall flags → link out).
6. **Watchlist upgrades**: scanner-backed columns (52wk H/L, Perf W/1M/3M/6M/Y/YTD, Recommend.All, avg volume) + sparklines from local cache + reorderable sections.
7. **Object-tree/drawing manager panel**: list+select+hide/lock/delete all drawings (parity `_objectTreeDialog`).
8. **Crosshair-rectangle modifier + "draw on all charts"-style sync (multi-tab symbol/interval sync)** — cheap completions of deferred items.
9. Order book / depth heat (DOM via exchange WS) — larger, later.
10. Pine-like formula bar — rejected (scope).

Suggested phase 5: items 1–3 (data infra + replay + templates). Phase 6: 4–7.
