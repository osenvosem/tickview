# TickView (reference-app-parity chart app, Rust + egui) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a native Rust+egui application reproducing the reference desktop app's user-facing functionality: full interactive charting, ~110 built-in indicators with reference names/defaults/colors, watchlist, symbol search, panes, drawings, alerts, themes, persistence.

**Architecture:** Four crates in one workspace: `ta` (pure indicator math + registry, zero UI/net deps), `marketdata` (provider abstraction: Binance/Nasdaq/CBOE/Frankfurter/Yahoo + reference search, SQLite cache, resampler, live feeds), `tickchart` (egui custom widget: scales, painter, panes, interactions, drawings), `app`/bin `tickview` (eframe shell: top bar, search, indicators dialog, watchlist, alerts, settings, persistence). Data flows: provider → cache → `Vec<Bar>` → indicators recomputed → chart state → egui paint; worker threads + crossbeam channels into the UI loop.

**Tech Stack:** Rust 1.99 (2024 edition), eframe/egui/egui_logrer? — eframe, egui, egui_extras; ureq (blocking HTTP/1.1+2), tungstenite (WS), crossbeam-channel, serde+serde_json, rusqlite(bundled), chrono+chrono-tz, thiserror, anyhow, rand/serde_json fixtures, rodio (sounds), tracing+tracing-subscriber.

**Spec:** `docs/superpowers/specs/2026-10-18-tickview-design.md`

## Global Constraints

- Edition 2024; rustc ≥ 1.85; workspace lints: deny clippy::correctness, warn suspicious/style/complexity/perf; `cargo fmt` enforced; no `unsafe` anywhere.
- Zero API keys required on default path; every provider optional and hot-disabled on failure (per-provider circuit breaker, documented status in UI).
- Indicator names, input defaults, plot colors byte-match `research/studies/meta/*.json` (parity test `xtask parity`). Formulas: textbook/Pine semantics; deviations logged in `docs/quirks.md`.
- No `println!` in lib crates; `tracing` facades only; app installs subscriber.
- `Bar { t: i64 /*unix secs, bucket start UTC*/, o,h,l,c,v: f64 }` single definition lives in `ta::bar`, re-exported by all crates.
- Unicode default colors: up `#26a69a`, down `#ef5350`, main blue `#2962FF`, accent orange `#FF6D00` (reference palette). Dark bg `#131722`, panel `#1E222D`, border `#2A2E39`, text `#D1D4DC`, muted `#787B86`; light equivalents reference-style.
- Native menu bar labels, tooltips EN only. Window title "TickView".

## Review Focus

- Partial/empty provider payloads (Yahoo 429, Nasdaq non-JSON html page): every parse path must return typed error, UI shows degraded banner, never blank-crashes.
- Empty/short series warm-up (< period bars): all indicator outputs NaN-padded to input length, legend shows "–", scale fits without panicking on all-NaN.
- Window resize to tiny (200×300) and huge (5000px): chart layout, panes, legend collapse without panic or zero-div.
- Bar with o==h==l==c and volume 0: painter draws 1px body, volume band zero-height, log scale shift guard (prices ≤0 clamp epsilon).
- Cold boot offline: app opens from SQLite cache within 2s, marks each symbol "cached stale", watchlist renders; no blocking on network timeout > 1.5s UI stall.
- Re-adding same indicator twice (two instances) and symbol switch with open drawings: instances persist per-tab, drawings stay attached to (t,price) anchors of new symbol? → drawings per symbol; on symbol change drawings hidden+restored.
